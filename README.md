## 🔥 Featured Projects

### 🧠 1. ReasonEval – LLM Reasoning Evaluation Engine
AI system to evaluate and score reasoning quality of LLM outputs.

- Evaluates:
  - Logical consistency
  - Completeness
  - Instruction following
  - Hallucination risk  
- Built interactive dashboard using **Streamlit**
- Runs locally using **Ollama (Llama models)**  
- Uses **self-verification + first-principles reasoning approach**

---

### 🛡 2. SafeVision – AI Surveillance System
Real-time intelligent CCTV system with advanced threat detection.

- 🚨 Features:
  - Intrusion detection (custom zones)
  - Face recognition access control
  - Mask & weapon detection
  - WhatsApp alerts (Twilio integration)
- Built with **YOLOv8 + OpenCV + Flask**
- Optimized for real-time performance

---

### 🌍 3. Multilingual Translator & Summariser
End-to-end NLP system supporting 50+ languages.

- 🔤 Features:
  - Auto language detection
  - TF-IDF extractive summarisation (~70% reduction)
  - Tone detection
  - Text-to-Speech (30+ languages)
- Built using **Python, FastAPI, NLTK, gTTS**
- Includes **custom Hinglish + multilingual detection pipeline**

---

### 🧬 4. Skin Cancer Classification System
AI model for classifying dermoscopic images (AK, BCC, SK).

- 🔥 Features:
  - GradCAM explainability
  - Confidence scores
  - Interactive UI for predictions
- Tech: **PyTorch, OpenCV, Streamlit**

---

### 🎭 5. Real-Time Emotion Detection System
Detects human emotions from live webcam feed.

- Uses **CNN + Haar Cascade + OpenCV**
- Real-time face detection and emotion classification
- Built with **TensorFlow/Keras**

---

### 🎥 6. Deepfake Detection System
Detects manipulated videos using facial and temporal analysis.

- Pipeline includes:
  - Face extraction
  - Feature analysis
  - ML-based classification
- Tech: **PyTorch, MediaPipe, FastAPI, Streamlit**

---

### 🌾 7. AgriPredict – Smart Crop Yield Forecasting
ML-based agricultural decision system.

- Uses **soil + weather + regional data**
- Includes:
  - Voice assistant
  - Suitability prediction
  - Real-time weather integration

### 🌱 8. IoT Slurry Utilisation & Smart Irrigation System
Automation system for sustainable agriculture.
